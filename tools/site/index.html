Velk skill

The Claude Code skill for building, deploying and maintaining Velk sites.

Install

In a Claude Code session:

/plugin install velk --marketplace elleven-digital/velk-skill

Or from a terminal:

claude plugin install velk --marketplace elleven-digital/velk-skill

In the Claude app: Customize → Plugins → Add → Add marketplace, enter elleven-digital/velk-skill, then add velk.

Without the plugin

Ask Claude Code:

Install the Velk skill from skill.velkcms.com into ~/.claude/skills/velk

Or install it yourself:

mkdir -p ~/.claude/skills/velk
curl -fsSL https://skill.velkcms.com/velk-skill-latest.tar.gz \
  | tar xz --strip-components=1 -C ~/.claude/skills/velk

Run the same command again to update.

Files

velk-skill-latest.tar.gz — current release
versions.json — every version, with sha256
